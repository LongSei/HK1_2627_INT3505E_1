BTVN 1 · Resource Design: Thư viện

Giả định: thư viện có nhiều đầu sách, mỗi đầu sách có nhiều bản sao; độc giả mượn từng bản sao, hạn trả 14 ngày; một đầu sách có thể có nhiều tác giả.

1a. ERD (conceptual)

BOOK – AUTHOR là quan hệ nhiều – nhiều, tách qua BOOK_AUTHOR (một đầu sách có ≥ 1 tác giả). BOOK – COPY, COPY – LOAN, MEMBER – LOAN: một – nhiều.

erDiagram
    BOOK ||--|{ BOOK_AUTHOR : "có"
    AUTHOR ||--o{ BOOK_AUTHOR : "viết"
    BOOK ||--o{ COPY : "có bản sao"
    COPY ||--o{ LOAN : "được mượn"
    MEMBER ||--o{ LOAN : "mượn"

1b. ERD chi tiết (thuộc tính, khoá)

PK = khoá chính, FK = khoá ngoại, UK = duy nhất.

erDiagram
    BOOK ||--|{ BOOK_AUTHOR : "có"
    AUTHOR ||--o{ BOOK_AUTHOR : "viết"
    BOOK ||--o{ COPY : "có bản sao"
    COPY ||--o{ LOAN : "được mượn"
    MEMBER ||--o{ LOAN : "mượn"
    BOOK {
        int id PK
        string title
        string isbn UK
        int published_year
    }
    AUTHOR {
        int id PK
        string name
    }
    BOOK_AUTHOR {
        int book_id PK, FK
        int author_id PK, FK
    }
    COPY {
        int id PK
        int book_id FK
        string barcode UK
        string status "available | borrowed"
    }
    MEMBER {
        int id PK
        string full_name
        string email UK
        string membership_type
    }
    LOAN {
        int id PK
        int copy_id FK
        int member_id FK
        datetime borrowed_at
        date due_date
        datetime returned_at
    }

2. URL list (14 endpoints, base /api/v1)

#MethodURLMô tảBodyStatus
1GET/books?q=&author_id=Tìm / lọc đầu sách—200
2POST/booksThêm đầu sách{title, isbn, publishedYear, authorIds}201, 400
3GET/books/{bookId}Chi tiết đầu sách—200, 404
4PATCH/books/{bookId}Sửa đầu sách{title?, isbn?, publishedYear?}200, 400, 404
5DELETE/books/{bookId}Xoá đầu sách—204, 404, 409
6GET/books/{bookId}/copiesBản sao của đầu sách—200, 404
7POST/books/{bookId}/copiesThêm bản sao{barcode}201, 404
8GET/authorsDanh sách tác giả—200
9GET/authors/{authorId}/booksSách của tác giả—200, 404
10POST/membersĐăng ký độc giả{fullName, email, membershipType}201, 400
11GET/members/{memberId}Thông tin độc giả—200, 404
12POST/loansMượn sách{copyId, memberId}201, 400, 409
13GET/loans?member_id=&status=Danh sách lượt mượn—200
14PATCH/loans/{loanId}Trả sách{"status": "returned"}200, 404, 409

Body: ? = không bắt buộc; GET và DELETE không có body. Server tự sinh id, client không gửi.

Bản sao phụ thuộc đầu sách nên dùng nested URL /books/{id}/copies; lượt mượn liên quan cả bản sao và độc giả nên để top-level /loans và lọc bằng ?member_id=.
